✨ 具体改动

  • 主题工具栏由纯色改为 135° 蓝紫渐变（bg_toolbar.xml），三个页面统一。
  • 列表新增未读蓝点（头像左侧 8dp 圆点，未读才显示），一眼区分已读/未读。
  • 头像发件人头像加 2dp 白色描边，从扁平色块变为精致圆形徽标。
  • 卡片所有卡片圆角提至 16dp，加 1dp 浅描边 + 轻微 elevation，层次更清晰。
  • FAB悬浮写信按钮改为橙黄渐变圆形，质感更立体。
  • 筛选分类 chip 圆角统一为 16dp，选中态更圆润。
  • 详情邮件详情头部信息区升级为独立卡片（留白 + 阴影），与正文/附件卡风格统一。
  • 对话框AI 设置「测试」按钮套用主色样式；账户添加/管理的输入框、Spinner、删除按钮全部卡片化（删除按钮红色警示）。
  • 配色头像色板与分类标签色改用更协调的现代色系（蓝/绿/橙/红/紫/青/粉/橙）。

📦 如何安装 / 更新

方式一（应用内）：已装旧版可直接在右上角菜单「检查更新」→ 一键下载安装 v1.14。
方式二（手动）：用本地构建的 MailMaster-v1.14-debug.apk 覆盖安装（与本地旧 debug 版同签名）。
远端 CI 已生成 Release：v1.14，含 4 个国内镜像加速地址，update.json 校验通过。

⚠️ 关于签名一致性：CI 发布的 Release（MailMaster-v1.14.apk）使用统一发布签名，而本地手动构建的是 debug 签名。 若你手机上装的是本地 debug 版，应用内「点更新」下载的是 CI release 版（签名不同），覆盖安装会失败。 建议统一安装 CI Release 版（或从 CI 下载的 v1.14 直接安装），「点更新」链路即可正常工作。
